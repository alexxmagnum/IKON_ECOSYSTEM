# 11 — RECOMMENDATION_ENGINE

## Objetivo

Definir el sistema inteligente de recomendaciones de IKON.

El Recommendation Engine será el encargado de mostrar a cada usuario las experiencias, actividades y oportunidades más relevantes en cada momento.

Su objetivo no es aumentar el tiempo de uso de la aplicación.

Su objetivo es aumentar el valor de cada visita al club.

---

# Filosofía

Una buena recomendación no vende.

Ayuda.

IKON no intentará convencer al usuario de hacer algo.

Intentará mostrarle aquello que realmente puede interesarle.

Cada recomendación deberá sentirse útil.

Nunca invasiva.

---

# Objetivos

El sistema debe ayudar a:

* descubrir experiencias,
* completar actividades,
* aumentar la ocupación,
* mejorar la satisfacción,
* conectar personas,
* incrementar la recurrencia.

---

# Qué puede recomendar

El sistema podrá recomendar:

* experiencias,
* eventos,
* torneos,
* partidas,
* compañeros,
* mesas compartidas,
* platos,
* promociones,
* bebidas,
* actividades,
* instalaciones,
* horarios.

---

# Cuándo recomendar

Las recomendaciones dependerán del contexto.

Por ejemplo.

Antes de reservar.

Durante una visita.

Después de terminar una actividad.

Cuando exista una oportunidad relevante.

Nunca continuamente.

---

# Contexto

Las recomendaciones podrán considerar:

* día de la semana,
* hora,
* clima,
* ocupación,
* historial,
* intereses,
* deporte favorito,
* disponibilidad,
* reservas activas,
* amigos presentes,
* eventos cercanos.

Siempre respetando la privacidad.

---

# Ejemplos

## Caso 1

Reserva de golf.

↓

Se recomienda una comida posterior.

---

## Caso 2

Reserva de restaurante.

↓

Se propone música en directo esa noche.

---

## Caso 3

Dos personas buscan compañero.

↓

El sistema detecta compatibilidad.

↓

Sugiere crear una partida.

---

## Caso 4

Baja ocupación.

↓

Se destacan experiencias disponibles.

Nunca mediante spam.

---

# Personalización

Cada usuario tendrá una experiencia diferente.

No existirá una portada idéntica para todos.

La aplicación se adaptará continuamente.

---

# Relevancia

La prioridad nunca será mostrar más contenido.

La prioridad será mostrar el contenido correcto.

Una única recomendación excelente vale más que diez irrelevantes.

---

# Transparencia

Las recomendaciones deberán ser comprensibles.

El usuario nunca debe sentir que el sistema actúa de forma misteriosa.

---

# Integración

El Recommendation Engine trabajará con:

* Experience Engine.
* Community Engine.
* Gamification Engine.
* Restaurante.
* Carta.
* Reservas.
* Torneos.
* Eventos.
* Notificaciones.
* Automatizaciones.

Nunca funcionará de forma aislada.

---

# Lo que nunca hará

Nunca mostrará contenido únicamente porque genere ingresos.

Nunca ocultará opciones relevantes.

Nunca manipulará al usuario.

Nunca enviará recomendaciones repetitivas.

Nunca interrumpirá experiencias importantes.

---

# Indicadores

Mediremos:

* recomendaciones aceptadas,
* experiencias descubiertas,
* reservas originadas,
* aumento del consumo,
* satisfacción,
* recurrencia,
* participación.

---

# Evolución

El sistema aprenderá del comportamiento general del club.

No para vigilar personas.

Sino para mejorar continuamente la calidad de las propuestas.

---

# Regla final

La mejor recomendación es aquella que hace que el usuario piense:

"Justo era lo que me apetecía."

Si el usuario siente que IKON le entiende sin resultar invasivo,

el Recommendation Engine habrá cumplido su misión.
