# 03 — UX MANIFESTO

## Objetivo

Definir la experiencia que IKON debe transmitir a las personas.

Este documento no describe pantallas.

Describe cómo debe sentirse un usuario durante toda su relación con IKON.

Toda decisión de UX deberá respetar este manifiesto.

---

# Introducción

La experiencia de usuario no consiste en colocar botones correctamente.

Consiste en hacer que una persona disfrute utilizando el producto.

IKON no quiere que los usuarios aprendan una aplicación.

Quiere que disfruten del club.

La tecnología solamente debe hacerlo posible.

---

# Nuestra filosofía

Cada interacción debe acercar a una persona a una experiencia.

Nunca solamente a una función.

Reservar no es el objetivo.

Comer no es el objetivo.

Jugar no es el objetivo.

El objetivo siempre será vivir una experiencia mejor.

---

# Cómo debe sentirse el usuario

Cuando una persona utiliza IKON queremos que sienta:

## Bienvenida

Desde el primer segundo debe sentir que pertenece al club.

No debe sentirse como un visitante.

Debe sentirse esperado.

---

## Claridad

Nunca debe preguntarse:

¿Qué hago ahora?

El sistema siempre debe mostrar el siguiente paso.

---

## Descubrimiento

Cada vez que abra IKON debe descubrir algo.

Una experiencia.

Una persona.

Un evento.

Una oportunidad.

Nunca debe parecer que todo está igual.

---

## Inspiración

IKON no debe limitarse a informar.

Debe inspirar.

Las imágenes.

Las historias.

Los eventos.

La gastronomía.

Todo debe despertar ganas de participar.

---

## Confianza

El usuario nunca debe tener miedo a equivocarse.

Las acciones importantes serán claras.

Las consecuencias serán comprensibles.

Siempre podrá corregir errores.

---

## Fluidez

La experiencia debe sentirse continua.

Nunca fragmentada.

Nunca pesada.

Nunca lenta.

---

## Exclusividad

IKON debe transmitir que pertenece a un lugar especial.

No mediante barreras.

Sino mediante calidad.

---

## Calma

El producto nunca debe generar estrés.

Nunca saturar.

Nunca parecer caótico.

Todo debe respirar.

---

## Alegría

Queremos que utilizar IKON resulte agradable.

No únicamente útil.

---

## Comunidad

El usuario nunca debe sentirse solo.

Siempre debe percibir que existen otras personas disfrutando del club.

---

# Antes de llegar

IKON ayuda al usuario a imaginar la experiencia.

No solamente a organizarla.

Debe despertar ilusión.

---

# Durante la visita

IKON acompaña.

Nunca interrumpe.

Nunca roba protagonismo al momento real.

El club siempre es más importante que la aplicación.

---

# Después de la visita

IKON mantiene viva la relación.

No mediante spam.

Mediante recuerdos, propuestas y nuevas oportunidades.

---

# La comunidad

Queremos reducir el miedo a participar.

Organizar una partida.

Buscar compañeros.

Crear una experiencia.

Todo debe resultar sencillo.

---

# El diseño

El diseño nunca debe impresionar por exceso.

Debe impresionar por equilibrio.

Cada detalle debe parecer inevitable.

---

# El movimiento

Las animaciones nunca deben llamar la atención.

Deben hacer que todo resulte más natural.

---

# El contenido

El contenido debe emocionar.

Las fotografías.

Los platos.

Los eventos.

Las historias.

Las personas.

Nunca utilizaremos contenido únicamente para llenar espacio.

---

# La velocidad

Esperar rompe la experiencia.

Siempre que sea posible:

La información aparecerá inmediatamente.

Las transiciones ocultarán tiempos de carga.

El usuario nunca debe sentir que el sistema está trabajando.

---

# Los errores

Un error nunca debe convertirse en una frustración.

Siempre ofreceremos:

* explicación,
* solución,
* siguiente paso.

---

# La inteligencia

La inteligencia debe sentirse como una ayuda.

Nunca como vigilancia.

Nunca como publicidad.

Nunca como presión.

---

# La aplicación ideal

La mejor experiencia ocurre cuando el usuario deja de pensar en la aplicación.

Simplemente disfruta del club.

Ese será siempre nuestro objetivo.

---

# Regla final

Si una decisión mejora el software pero empeora la experiencia humana,

la decisión es incorrecta.

IKON existe para mejorar la experiencia de las personas.

Nunca al contrario.
