## Objetivo

Definir el sistema de gestión, organización, distribución y reutilización de todo el contenido de IKON.

El Content Engine permitirá que cualquier contenido pueda alimentar múltiples experiencias dentro del ecosistema.

El contenido será un activo estratégico.

No un simple archivo almacenado.

---

# Filosofía

Cada contenido creado para IKON deberá poder reutilizarse.

Una fotografía.

Un vídeo.

Un evento.

Una noticia.

Un plato.

Una promoción.

Todo deberá poder aparecer automáticamente en diferentes partes del producto.

Nunca existirá contenido aislado.

---

# Objetivos

El Content Engine debe permitir:

* crear contenido fácilmente,
* reutilizar contenido,
* mantener el contenido actualizado,
* distribuir contenido automáticamente,
* enriquecer experiencias,
* reducir trabajo manual.

# Reutilización

Un mismo contenido podrá aparecer simultáneamente en:

* Home.
* Experiencias.
* Restaurante.
* Eventos.
* Perfil.
* Recomendaciones.
* Búsqueda.
* Notificaciones.

Nunca será necesario duplicarlo.

---

# Organización

Todo contenido deberá disponer de:

* título,
* descripción,
* categoría,
* etiquetas,
* fecha,
* autor,
* estado,
* visibilidad,
* idioma,
* imágenes,
* vídeo.

---

# Estados

Todo contenido tendrá un estado.

Borrador.

↓

Revisión.

↓

Publicado.

↓

Archivado.

Nunca existirá contenido sin estado.

---

# Programación

El contenido podrá publicarse automáticamente.

Ejemplos.

Promoción del viernes.

↓

Publicar jueves.

↓

Ocultar domingo.

Todo sin intervención manual.

---

# Multimedia

Las imágenes deberán admitir:

* diferentes tamaños,
* optimización automática,
* formatos modernos,
* recorte inteligente.

Los vídeos deberán:

* cargarse rápidamente,
* adaptarse al dispositivo,
* reproducirse cuando aporte valor.

# Integración

El Content Engine alimentará:

* Home.
* Social Experience Engine (SoT: `48`; este doc `14` está SUPERSEDED por `52`).
* Recommendation Engine (SoT: `50`).
* Restaurant.
* Digital Menu.
* Event.
* Notification Engine (SoT: `49`).
* CMS.
* SEO.

Nunca será un sistema independiente.

---

# SEO

El contenido editorial deberá contribuir al posicionamiento orgánico.

El contenido no existirá únicamente para los usuarios actuales.

También ayudará a atraer nuevos visitantes.

---

# Personalización

No todos los usuarios verán el mismo contenido.

El sistema podrá priorizar según:

* intereses,
* actividad,
* idioma,
* preferencias,
* contexto.

---

# Caducidad

El contenido tendrá un ciclo de vida.

Una vez deja de ser relevante,

deberá archivarse automáticamente o perder prioridad.

Nunca queremos un club con contenido antiguo ocupando espacio principal.

---

# Calidad

Publicaremos menos contenido.

Pero mucho mejor.

La calidad siempre será más importante que la cantidad.

---

# Automatización

El sistema podrá:

* reutilizar fotografías,
* reutilizar vídeos,
* generar galerías,
* destacar contenido,
* preparar campañas,
* alimentar recomendaciones.

Siempre respetando las decisiones editoriales.

---

# Indicadores

Mediremos:

* visualizaciones,
* interacción,
* reutilización,
* conversión,
* tiempo de lectura,
* contenido compartido,
* impacto sobre reservas.

---

# Lo que nunca hará

Nunca publicará contenido únicamente para llenar espacio.

Nunca duplicará información.

Nunca obligará a mantener varias versiones del mismo contenido.

Nunca permitirá que el contenido antiguo degrade la percepción del club.

---

# Regla final

Todo contenido debe responder a una pregunta.

¿Ayuda a crear una mejor experiencia dentro de IKON?

Si la respuesta es no,

ese contenido probablemente no debería existir.
