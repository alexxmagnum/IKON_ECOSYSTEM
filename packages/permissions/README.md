# @motanos/permissions

RBAC types and helpers for MotanOS.

## Roles

Canonical roles come from DEC-002:

Guest, Member, Socio, Organizer, Staff, Manager, Club Admin, Platform Admin.

Phase 2 helpers emphasize: Platform Admin, Club Admin, Staff, Member.

## Notes

- No invented roles
- No domain ownership here
- No database queries in this package yet
